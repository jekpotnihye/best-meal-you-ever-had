One sentence, at most 200 characters, about the best meal ever had: a grandmother's rendang, simmered until the coconut milk turned to oil, eaten standing in her kitchen, too impatient for a plate.

## Run it

```sh
python3 main.py
```

The program writes the one-sentence entry, and nothing else, to `/output/entry.txt`.
